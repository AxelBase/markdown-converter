Supported Markdown Syntax and CommonMark Compliance

Published: January 07, 2026

AxelBase adheres closely to the CommonMark specification, ensuring consistent and predictable conversion of Markdown to HTML. This compliance means your documents render the same way across different tools and platforms.

Headings are supported from level 1 to 6 using hash prefixes. Each heading translates to the corresponding h1 through h6 tag with proper hierarchy for accessibility and SEO.

Emphasis handling includes bold text via double asterisks or underscores, and italics with single markers. Nested emphasis, such as bold within italics, works as expected.

List and Link Support

Lists come in both unordered and ordered varieties. Bullet points use dashes, asterisks, or plus signs, while numbered lists accept any starting number. Nested lists maintain correct indentation and tagging.

Links follow the standard bracketed text with parenthetical URL format. The converter generates proper a tags with href attributes. Relative links preserve their paths for use in static sites.

Images use the exclamation mark prefix, producing img elements with src and alt attributes. The alt text becomes accessible descriptions, improving inclusivity.

Inline code spans wrap text in backticks, resulting in code tags for monospaced display. Fenced code blocks with triple backticks allow language specification for potential highlighting in downstream tools, though preserved as pre and code elements.

Blockquotes use the greater-than symbol, rendering as blockquote tags that can contain other elements like paragraphs or lists for rich quoted content.

Tables are supported through the pipe syntax, converting to proper table, tr, th, and td structures with optional alignment specifiers.

Horizontal rules created by three or more dashes, asterisks, or underscores become hr elements for section separation.

The converter handles edge cases gracefully, such as lazy continuation lines in lists and proper escaping of special characters.

This broad syntax support covers most everyday writing needs, from technical documentation to blog posts and educational materials.

FAQ

Does it support task lists?

Standard checkbox syntax renders as plain list items without interactive checkboxes.

What about footnotes?

Basic inline links serve similar purposes, though dedicated footnote syntax is not implemented.

Are HTML embeds allowed?

Direct HTML input gets sanitized for security, allowing only safe elements.

How are line breaks handled?

Two trailing spaces or double newlines create br or p separations appropriately.

Does it support emojis?

Yes, emoji shortcodes and Unicode characters render directly.

Understanding supported syntax helps you write confidently.
